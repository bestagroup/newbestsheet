# نسخه 3.6.0 — بازطراحی داشبورد

این نسخه فقط رابط داشبورد را بازطراحی می‌کند. منبع داده، محدودیت نقش‌ها، پورتفوی فعال و قواعد گزارش‌دهی صورت‌های مالی تأییدشده نسخه 3.5 بدون تغییر باقی مانده‌اند.

## تغییرات

- هشدارهای سررسید و جلسات پیش‌رو در بالای صفحه؛ هشدارهای معوق ابتدا نمایش داده می‌شوند.
- کارت‌های خواناتر، تفکیک حوزه‌های مجاز در تب‌ها، پرونده‌های تخصیص‌یافته و فعالیت‌های اخیر، پروفایل جمع‌شونده و حفظ یادآوری تولدها.
- جست‌وجوی چندکلمه‌ای، یکسان‌سازی حروف و ارقام فارسی/عربی، گزینه عبارت پیوسته، فیلتر نوع رکورد، پاک‌سازی و شمارنده نتایج.
- جستجو فقط در رکوردهای اخیر بارگذاری‌شده است و آمار یا نمودار را فیلتر نمی‌کند؛ این محدودیت در رابط توضیح داده شده است.
- Chart.js موجود پروژه؛ بارگذاری نمودار هنگام نمایش تب، راهنمای رقم دقیق بدون گرد کردن رشته مبلغ، جدول قابل باز شدن و جایگزین در نبود کتابخانه نمودار.
- پیمایش تب با صفحه‌کلید راست‌چین، عنوان‌های دسترس‌پذیر، تمرکز قابل مشاهده، احترام به کاهش حرکت و سبک‌های واکنش‌گرا و تیره.
- بدون JavaScript همه حوزه‌های مجاز و جدول‌های داده در دسترس می‌مانند؛ کنترل‌های جستجوی غیرفعال نمایش داده نمی‌شوند.

## اعتبارسنجی

- آزمون‌های PHP با پایگاه SQLite درون حافظه و آزمون تعامل‌های JavaScript اجرا می‌شوند؛ نتیجه نهایی CI پس از انتشار ثبت خواهد شد.
- آزمون‌های JavaScript از بدل DOM و Chart استفاده می‌کنند و جایگزین آزمون بصری مرورگر نیستند.
- مرورگر محلی نصب نبود و دریافت Chromium موفق نشد؛ بنابراین صحت بصری نهایی در اندازه‌های دسکتاپ/موبایل ادعا نمی‌شود. پیش از استقرار، صفحه واقعی در عرض‌های ۳۷۵، ۷۶۸ و ۱۴۴۰، حالت تیره و نقش‌های مختلف بازبینی شود.

دستورها:

```sh
vendor/bin/phpunit
node --test tests/Frontend/dashboard.test.cjs
php artisan view:cache
```

این نسخه migration یا تغییر وابستگی ندارد. هیچ پایگاه عملیاتی تغییر نکرده و استقرار روی سرور تولید انجام نشده است. پس از دریافت نسخه در سرور، کش view قبلی پاک/بازسازی شود؛ فایل‌های CSS/JS دارای نسخه 3.6.0 هستند.
