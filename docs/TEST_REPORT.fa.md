# گزارش آزمون — ۲۰۲۶-۱۰-۰۹

## نتیجه اجرا

- **۶۱ آزمون، ۳۷۴ assertion، بدون شکست و خطا** با PHPUnit 11.5.56.
- محیط: PHP 8.3.6، Laravel 12.61، SQLite در حافظه برای suite.
- ۳۴۰ فایل PHP برنامه/تنظیمات/migration/route/test از نظر syntax بررسی شدند: صفر خطا.
- کامپایل Blade، cache تنظیمات و cache مسیرها موفق بودند؛ cacheهای محیط بررسی از بسته خروجی حذف شده‌اند.
- ۱۵ صفحه اصلی با middleware واقعی از سمت سرور رندر شدند. این آزمون، اجرای JavaScript و تعامل مرورگر را تأیید نمی‌کند.
- نصب تازه و seed تکرارپذیر در آزمون یکپارچه اجرا شد.
- ارتقا از schema قبل از دو migration جدید در SQLite فایل‌محور اجرا شد. مبلغ 9007199254740993 و صورت مالی قبلی حفظ شدند؛ نوع legacy اعمال شد و دوره annual همان سال/ماه بدون تداخل ثبت شد.

## تفکیک شواهد

`tests/Feature/EnterpriseIntegrationTest.php` از migration و seed واقعی استفاده می‌کند و middleware را فعال نگه می‌دارد. بخشی از آزمون‌های قدیمی suite از schema کوچک‌شده یا mock و middleware غیرفعال استفاده می‌کنند؛ تعداد کل آزمون‌ها به معنی آزمون سرتاسری همه صفحات نیست.

آزمون‌های افزوده شامل ثبت طرح و ۲۰ مرحله، کنترل نقش و رکورد، مسیرهای پرداخت و idempotency، حفظ تاریخچه حذف، تفکیک دوره مالی، rollback هنگام شکست audit، پرونده فاقد صورت مالی، جمع ترانش، چرخه مجمع و مصوبه، نامه و محرمانگی، قرنطینه/دسترسی/بازیابی فایل، محافظت پیوست، دارایی و کارمند، عضویت مکاتبه، عدم اجرای script و تقویم هستند. تست عددی نیز جمع دقیق ارقام بزرگ را بررسی می‌کند.

## اجرا‌نشده‌ها

- MySQL/MariaDB: تلاش اجرای سرویس با محدودیت ساخت socket محیط متوقف شد؛ آزمون موفق DB تولید گزارش نمی‌شود.
- آزمون مرورگر، بار و نفوذ مستقل، بازیابی پشتیبان واقعی، هم‌زمانی چند worker و تراکنش‌های واقعی MySQL.
- Google Calendar واقعی، SMS، ایمیل، Pusher و ClamAV واقعی. رفتار همگام‌سازی Google با mock و شکست اسکن با فایل pending آزمایش شده است.
- اسکن آنلاین آسیب‌پذیری وابستگی‌ها.

## بازتولید

```sh
php vendor/bin/phpunit --log-junit test-results.xml
php artisan view:cache
php artisan config:cache
php artisan route:cache
```

فرمان‌های cache باید با تنظیمات همان محیط اجرا شوند. لاگ خام suite و شواهد مهاجرت در `docs/evidence` هستند. چک‌لیست پذیرش عملیاتی در `UAT_CHECKLIST.fa.md` است.
