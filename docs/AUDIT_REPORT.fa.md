# گزارش بازبینی فنی و عملکردی

مبنای بررسی: کد ZIP تحویلی، ساختار داده، مسیرهای وب و آزمون‌های موجود؛ دسترسی به داده عملیاتی، نیازمندی‌های حقوقی مصوب شرکت و سرور تولید وجود نداشت. این گزارش تأیید امنیت کامل یا انطباق حقوقی نیست.

## یافته‌های اصلاح‌شده

| مسئله | اصلاح |
|---|---|
| کنترل ناکافی دسترسی پرونده، صورتجلسه و رسانه | افزودن کنترل رکورد و حذف اتکا به مجوز عمومی فایل‌منیجر |
| امکان دسترسی به گفت‌وگوی پرونده بدون عضویت در آن | محدودکردن مشاهده مکاتبات داخلی به اعضای واقعی گفت‌وگو |
| تعبیه ناامن متن مکاتبه داخل script | JSON escaping مناسب و اصلاح کدگذاری دوگانه متن |
| ریسک ارتقای دسترسی توسط مدیر واگذارشده | محدودسازی نقش‌های سیستمی و تغییر کاربران قدرتمند |
| محاسبه ترانش با MAX | تغییر به SUM برای لحاظ‌کردن چند پرداخت در یک ترانش |
| دو مسیر مستقل ثبت پرداخت | تجمیع در FinanceService با اعتبارسنجی، قفل و idempotency |
| حذف/تغییر مالی فاقد تصویر قابل پیگیری | ثبت اجباری تصویر رویداد در تراکنش پرداخت و صورت مالی |
| تداخل صورت سالانه و فصل چهارم | افزودن نوع دوره به داده و کلید یکتا |
| حذف شرکت فاقد صورت مالی از گزارش | حذف شرط وجود صورت مالی از مجموعه اصلی گزارش |
| از دست رفتن دقت جمع مبالغ بزرگ | جمع و قالب‌بندی دقیق در گزارش‌های اصلاح‌شده |
| امکان تزریق فرمول در CSV | خنثی‌سازی پیشوند فرمول در سلول متنی خروجی |
| حذف فیزیکی اسناد و ناسازگاری بازیابی | نگهداری بایت‌ها، سطل بایگانی، بررسی وجود فایل هنگام بازیابی |
| فایل پیوست قابل حذف/انتقال و اتصال فایل بدون مالکیت | کنترل مرجع و مالکیت در مسیرهای جدید |
| حذف پروژه با سوابق وابسته | سرویس مشترک حذف و جلوگیری از حذف سوابق مالی/حقوقی |
| فقدان ثبت مستقل مجامع و دفتر نامه | ایجاد مدل، migration، سرویس، صفحه و آزمون |
| نبود اجرای اسکن فایل‌های pending | فرمان اسکن و زمان‌بندی با ماندن فایل در قرنطینه هنگام خطا |

| فرایند سرمایه‌گذاری | کنترل دسترسی و مدرک اجباری تأییدشده اصلاح شد | تصمیم تکراری و مدرک ناقص آزموده شد؛ تنظیم الزامات تابع شرکت است |
| پرونده طرح/شرکت | دسترسی، پیوند سند و حذف وابستگی اصلاح شد | منع دسترسی کارشناس نامرتبط و حذف پرونده دارای پرداخت |
| مکاتبات داخلی/خارجی | داخلی اصلاح؛ ثبت نامه ورودی/خروجی و پیگیری افزوده شد | عضویت، متن script، محرمانگی و قفل نامه بسته؛ ارسال واقعی خارجی پیاده‌سازی/تأیید نشده |
| تقویم | محدوده تاریخ و مالکیت تغییر رویداد اصلاح شد | محدوده نامعتبر، مالکیت، همگام‌سازی Google با mock |
| کارکنان | ساختار و صفحات موجود حفظ؛ کنترل بایگانی اصلاح | چرخه ایجاد/ویرایش و منع بایگانی دارای دارایی؛ حقوق‌ودستمزد خارج از دامنه |
| اموال | ساختار موجود حفظ؛ تخصیص معتبر و چرخه بایگانی | ایجاد/ویرایش/حذف نرم و اتصال به کارمند؛ استهلاک حسابداری افزوده نشده |
| مجامع پورتفو | ماژول جدید دستور جلسه، شرکت‌کنندگان، مصوبات و پیگیری | چرخه کامل، تعارض نسخه، تکمیل تمام بندها و قفل نهایی؛ رأی وزنی/امضای دیجیتال ندارد |
| پرداخت پورتفو | ثبت/ویرایش/حذف از سرویس مشترک با سند و تاریخچه | درخواست تکراری/متعارض، مبالغ نامعتبر، تاریخچه و ترانش |
| صورت‌های مالی | تفکیک سالانه/فصلی/قدیمی، یکتایی و ثبت تاریخچه | همزیستی سالانه و فصلی، ارقام بزرگ، rollback در خرابی audit؛ تصویب چندمرحله‌ای ندارد |
| گزارش مدیریت | اصلاح داده مالی و افزودن وضعیت مجامع، مصوبات، قراردادها | شرکت بدون صورت مالی و جمع پرداخت؛ تعریف KPI و معیار حسابداری باید توسط شرکت تأیید شود |
| آرشیو مستقل | بارگذاری مستقل، دسترسی مالک، حذف نرم/بازیابی | دانلود غیرمجاز، بایت‌های حفظ‌شده، پیوست محافظت‌شده و قرنطینه؛ مدیریت نسخه کامل/OCR ندارد |

## موارد باز برای پذیرش تولید

۱. اجرای suite و سناریوهای هم‌زمانی در DB مقصد؛ قفل ردیفی MySQL با SQLite معادل نیست.
۲. آزمون مرورگر واقعی، راست‌به‌چپ، فرم‌های Ajax، بارگذاری و صفحات موبایل؛ رندر سرور جای آن را نمی‌گیرد.
۳. تست سرویس‌های واقعی Google، SMS، ایمیل، Pusher و ClamAV با حساب آزمایشی سازمان.
۴. تطبیق داده‌های قدیمی، واحد پول، مدارک الزامی، دسترسی نقش‌ها و اسناد عمومی قدیمی.
۵. آزمون حجم واقعی، بازیابی پشتیبان و نظارت workerها و زمان‌بند.
۶. بررسی وابستگی‌ها با منبع آسیب‌پذیری به‌روز در محیط دارای اتصال مجاز؛ اسکن وابستگی آنلاین در این بازبینی انجام نشده است.

این موارد به معنی شکست آزمون‌های انجام‌شده نیستند؛ محدوده‌ای هستند که هنوز شواهد اجرا برای آن‌ها نداریم. فایل ZIP یک نامزد انتشار قابل ارزیابی است، نه گواهی نهایی آمادگی تولید.
