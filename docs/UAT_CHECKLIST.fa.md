# چک‌لیست پذیرش در محیط آزمایشی

برای هر ردیف، نام آزمایشگر، تاریخ، نتیجه، تصویر/شناسه رکورد و شماره ایراد احتمالی ثبت شود. داده واقعی حساس را به محیط فاقد کنترل دسترسی منتقل نکنید.

| سناریو | نتیجه مورد انتظار |
|---|---|
| ثبت متقاضی با ارقام فارسی و اطلاعات معتبر/نامعتبر | پیام معتبر، شرکت و طرح مرتبط، بدون پرونده نیمه‌ساخته |
| ورود کارشناس مرتبط و نامرتبط به همان شناسه طرح | فقط کارشناس دارای تخصیص، دامنه مجاز را ببیند |
| تلاش عبور مرحله بدون مدرک اجباری یا با مدرک مردود | مسدود؛ پس از تأیید مدرک، جریان مجاز ادامه یابد |
| ارسال داخلی با متن فارسی و کاراکترهای HTML | نمایش متن بدون اجرای کد؛ شخص خارج گفت‌وگو دسترسی نداشته باشد |
| ثبت نامه ورودی/خروجی، ارجاع، بستن و ویرایش دوباره | شماره یکتا، مسئول قابل پیگیری، ویرایش نامه بسته مسدود |
| رویداد تقویم روی مرز ماه/سال و تغییر توسط کاربر دیگر | تاریخ درست و جلوگیری از تغییر غیرمجاز |
| کارمند فعال + دارایی تحویلی؛ سپس بایگانی کارمند | تا تعیین تکلیف دارایی فعال بایگانی انجام نشود |
| ایجاد مجمع با دو دستور و یک مصوبه | نهایی‌سازی مسدود؛ پس از تعیین نتیجه هر بند مجاز |
| ویرایش مجمع در دو پنجره و ارسال نسخه قدیمی | تعارض 409؛ تغییر جدید از بین نرود |
| پرداخت دوبار با همان درخواست و دوبار با شماره سند تکراری | یک پرداخت؛ تعارض اطلاعات و سند تکراری رد شود |
| پرداخت‌های متعدد یک ترانش و عدد بالاتر از ۲ به توان ۵۳ | جمع و جدول گزارش با سند مرجع دقیق تطبیق یابد |
| صورت سالانه و فصل چهارم یک سال | دو رکورد مستقل؛ رکورد تکراری همان نوع رد شود |
| شرکت دارای پرداخت بدون صورت مالی | از گزارش حذف نشود؛ فقدان صورت مالی مشخص باشد |
| فایل مستقل و فایل پرونده، دانلود کاربر نامرتبط | دسترسی محدود؛ فایل pending/infected دانلود نشود |
| حذف و بازیابی فایل معمولی و حذف پیوست نامه/مجمع | معمولی بازیابی شود؛ پیوست محافظت شود |
| اجرای migration روی کپی داده تولید و بازیابی پشتیبان | تعداد و مبالغ و پیوند اسناد حفظ و برگشت واقعاً ممکن باشد |
| مشاهده روی مرورگرهای هدف، موبایل و فرم‌های Ajax | پیام خطا/موفقیت، انتخابگر فایل، ارقام و چینش RTL درست |
| قطع سرویس‌های بیرونی و بازگشت آن‌ها | خطا قابل پیگیری؛ هیچ ارسال/پرداخت تکراری رخ ندهد |

ارسال خارجی، عملیات بانکی یا انتشار روی سرور تولید بخشی از این تحویل خودکار نبوده است. راه‌اندازی تولید پس از قبولی سناریوهای مرتبط با استفاده واقعی شرکت انجام شود.
